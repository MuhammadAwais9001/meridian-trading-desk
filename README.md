# Meridian — Live Crypto & Forex Desk

Educational trading desk that analyses public market data (crypto + forex), shows confluence signals, position sizing, and trade plans.

## Features
- Live crypto candles from Coinbase / OKX / Kraken
- Forex using official daily ranges + live quotes
- Multi-factor confluence engine (EMA, MACD, RSI, Stochastic, Bollinger, ADX, structure, candle patterns)
- Position sizing by risk %
- Simple backtest sample on the current chart
- Dark professional UI

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy for free (Vercel)

1. Go to https://vercel.com → Sign in with GitHub
2. Import this repository
3. Click Deploy

Free tier is enough for personal use.

## Important
This is an educational tool only. Signals are confluence scores from public data — not financial advice and not a guarantee of profit. You can lose money.
